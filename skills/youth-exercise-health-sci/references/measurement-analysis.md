# 测量与统计分析

## 暴露和干预量

区分习惯性身体活动、计划运动、实际完成量、体适能、屏幕时间、久坐与睡眠。问卷、自报日记、家长代报、EMA与设备并非可直接互换的测量。

设备数据登记型号、位置、采样频率、epoch、单位、校准、非佩戴/睡眠算法、有效天/日时长、周末覆盖、季节及处理版本。阈值需与年龄、设备、位置、算法匹配；不得把任意成人阈值移植到儿童。

- counts、原始加速度、ENMO、MIMS与MVPA分钟不是同一量纲；只有有依据的算法才能转换。
- 非佩戴或无效记录不等于久坐或零活动；低加速度不自动证明坐姿。
- 问卷回答为“天数”的条目不等于每日平均分钟数；不同回答者和回忆窗口保留区别。
- 先汇总到预设的个体暴露，再报告参与者数、有效天数和覆盖；分钟/设备窗口不成为新增独立样本。
- 研究24小时行为替代时，说明总时间约束、替代哪种行为、睡眠/非佩戴处理、零值处理与模型假设。成分数据或等时替代模型是分析选择，不自动构成干预或因果证据。

具体公开数据的设备代际差异与变量限制见[数据资源](public-data.md)，不默认跨周期合并。

## 适龄结局

| 领域 | 需要记录 | 常见解释错误 |
|---|---|---|
| 心肺/肌力/运动能力 | 适用年龄、协议、测试是否最大/次最大、绝对或体重标准化单位、熟悉化与安全排除 | 不同年龄执行不同测试却强拼成一个指标 |
| 肥胖/心代谢 | 生长参考、年龄/性别标准化、空腹状态、检测方法、药物和青春期影响 | 用成人BMI阈值定义所有儿童肥胖；把子样本检测当全样本 |
| 骨健康 | DXA部位/设备、BMC或面积BMD、体型和生长因素、适龄参考 | 把指标变化直接等同骨折风险下降；忽略生长和骨大小 |
| 心理/认知/生活质量 | 年龄与语言验证、儿童自报或代理、量表方向、参考标准、测试练习效应 | 症状量表分数直接当临床诊断；混合不同报告者 |
| 实施与安全 | 招募覆盖、出勤、真实剂量、依从、退出原因、不良事件收集与分母 | 未报告事件等于无事件；出勤率等于全部剂量完成 |

结局测量的参考范围与量表使用许可按实际工具核查，不在技能内预设诊断阈值。

## 锁定分析

先写主要结局、时间点、组间对比/关联估计、统计单位、协变量依据、缺失、多重比较及敏感性分析。报告效应量和置信区间，区分统计、临床及实施意义；没有验证的儿童MCID就不要制造阈值。

试验的随机分组效应、依从方案效应与实际剂量关联属于不同估计目标。组间比较与亚组交互按[研究设计](study-design.md)处理。控制组变化也需保留，负结果不靠事后换终点挽救。

缺失记录原因和层次，包括整个学校退出、个体失访、设备无效和结局缺失；评估假设，选择合适模型/插补并做敏感性分析。ITT不意味着自动解决缺失；LOCF不作通用默认值。不能只删去低依从儿童后仍称随机试验主要结果。

复杂调查保留所需权重、分层与PSU；组件子样本和跨周期权重依据官方说明，不能只把权重当普通回归协变量。年龄子集按合理域分析处理，保留设计信息；同时报告未加权人数和加权估计。

观察研究按研究问题说明混杂、选择偏倚、测量误差及反向因果；不要按单变量P值筛出所有协变量。中介模型、倾向评分、MR或非线性模型都不免除识别假设。

## 非线性、剂量反应与预测

剂量反应先检验剂量定义、实际支持范围、样本密度和预设形状，区分处方剂量与完成剂量。避免在数据稀疏尾部宣称最佳剂量；样条拐点及亚组阈值需给不确定性和独立验证。

只有问题需要预测时才建立预测模型。患者/儿童及其所有时间窗、访视应留在同一分组；预测新学校时按学校评估。预处理、特征筛选、缺失处理、重采样、阈值与调参仅在训练流程拟合。考虑外部/时间验证、校准、合理基线及不确定性。不能随机拆分同一儿童的设备窗口，再称独立验证。

模型报告按适用的[TRIPOD+AI](https://www.bmj.com/content/385/bmj-2023-078378)；模型性能不证明运动的因果效果。期刊对公共数据计算研究的验证要求见[发表与伦理](publication-ethics.md)。

## 可复核交付

保存数据来源/许可/版本、同人匹配表、纳排流程、原始文件校验和、预处理参数、软件依赖、随机种子、分析代码、完整结果及方案变更。代码和图表以去标识的允许数据生成；学校/儿童ID与可识别信息分开管理。

先用小规模真实输入核对年龄、单位、合并键和设计矩阵，再扩展计算。不为还不存在的数据编写假结果，也不把演示/合成数据放入论文结果。
